<br>

**Numerical Validation Toolkit**
Mean, median, variance, and standard deviation with independent mathematical validation. Monte Carlo simulation for estimating π with reproducible seeding. Property-based testing with Hypothesis, edge-case and invalid-input handling, CLI interface, and performance benchmarking.

**Python Task Management API**
Full CRUD task management with request validation through Pydantic models, SQLite persistence, filtering, search, and pagination. Tests run against an isolated database so the suite never touches development data.

**Data Quality and ETL Pipeline**
Extraction, validation, cleaning, and transformation stages with checks for duplicates, missing values, invalid ages, out-of-range purchases, and malformed email addresses. Cleaned records load into SQLite.

**Python Log Anomaly Detector**
Structured log parsing into operational metrics and error-rate analysis, with detection for response-time outliers and repeated error patterns. Results persist to SQLite and export as CSV reports.
