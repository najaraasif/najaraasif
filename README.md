## Featured Project

### Numerical Validation Toolkit

A Python based numerical analysis and validation toolkit built with NumPy, pytest, and Hypothesis.

It includes:

* Statistical calculations for mean, median, variance, and standard deviation
* Monte Carlo simulation for estimating π
* Independent mathematical validation
* Property based testing with Hypothesis
* Edge case and invalid input handling
* Reproducible simulations
* Command line interface
* Performance benchmarking

The project currently has 17 automated tests covering numerical correctness, edge cases, invalid inputs, reproducibility, and mathematical properties.

I also benchmarked NumPy against a pure Python implementation using 1 million values and measured a 7.09x speedup in my test environment.
